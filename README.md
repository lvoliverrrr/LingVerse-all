# 灵界 (LingVerse) 游戏辅助脚本

这是一个针对灵界(LingVerse)网页游戏的用户脚本集合，旨在提升游戏体验和自动化一些重复性操作。

## 包含的脚本

目前包含以下4个脚本：

1. **玩家ID显示** - 显示玩家数字ID，方便添加道友
2. **神识精确数值** - 显示神识精确值而非百分比
3. **自动开藏宝图 / 自动挂机循环** - 自动开启藏宝图，并提供冥想-探索挂机原型
4. **修为简写显示** - 将修为显示为万/亿单位

---

### 1. 灵界 LingVerse 玩家ID显示 (lingverse-player-id.user.js)

这个脚本在主页状态栏、侧边栏和玩家资料面板显示当前玩家和其他玩家的数字ID，方便添加道友和拜访洞府。

#### 功能特点：
- 在顶部状态栏玩家名称后显示ID
- 在侧边栏角色信息区显示ID（境界下方）
- 在手机版状态栏显示ID
- 在查看其他玩家资料时，在名称旁显示其ID
- 点击ID可复制到剪贴板
- 复制成功显示提示

#### 安装方法：
1. 安装用户脚本管理器（如Tampermonkey、Greasemonkey或Violentmonkey）
2. 点击安装此脚本
3. 访问游戏网站即可生效

---

### 2. 灵界 LingVerse 神识精确数值显示 (lingverse-spirit-exact.user.js)

这个脚本将主页状态栏的神识百分比改回准确数值，并在使用神识时实时更新显示。

#### 功能特点：
- 将神识显示从百分比转换为精确数值（例如：120/200 而不是 60%）
- 显示神识恢复倒计时
- 实时更新神识数值
- 支持主界面和状态栏两处神识显示的更新

#### 安装方法：
1. 安装用户脚本管理器（如Tampermonkey、Greasemonkey或Violentmonkey）
2. 点击安装此脚本
3. 访问游戏网站即可生效

---

### 3. 灵界 LingVerse 自动开藏宝图 / 自动挂机循环 (lingverse-explore-helper.user.js)

这个脚本可以自动开启背包中的藏宝图，并提供外部脚本版的冥想-探索挂机循环，用于测试自动挂机体验后再决定是否合入游戏本体。

#### 功能特点：
- 自动扫描并开启背包中的藏宝图
- 支持批量处理，可设置每次开启的数量
- 遇到战斗时可自动雇用护道者
- 提供气运状态显示和统计信息
- 可配置护道者雇佣条件（最高费用、最低攻击力等）
- 支持多种作战模式和优先级设置
- 支持自定义冥想时长、最低神识阈值和自动探索倍率
- 自动探索运行或恢复挂起时，如果神识低于阈值、页面提示神识不足或长时间无进展，会主动回冥想；复制状态会说明当前神识、单次消耗和阈值
- 支持自定义事件/复活后的恢复窗口，适配慢网络或战斗结算较慢的账号
- 自动迎战、自动护道、奇遇/陌生道友处理后会进入同一个恢复窗口，神识足够时继续探索、神识不足时回冥想；复制状态会显示剩余秒数和恢复后的动作倾向
- 如果恢复窗口反复尝试重启自动探索但没有成功，复制状态会在“诊断归因”里显示事件/复活恢复后未能重启探索和自动探索入口失败原因
- 支持稳妥 1 倍 / 护道 1 倍 / 富裕 50 倍挂机预设，套用预设不会自动启动挂机
- 复制状态会显示当前配置是否匹配稳妥 1 倍、护道 1 倍或富裕 50 倍预设；偏离时会指出最接近的预设和关键差异，方便测试者复现同一挂机模式
- 富裕 50 倍预设默认带单轮资源保险丝：复活 1 次、用符 3 场、用丹 1 次；也可自定义，`0` 表示不限
- 支持自动购买云游商人最高价商品
- 复制状态会显示云游商人购买结果、商品名、价格、触发来源、脱敏失败消息和下一步建议，方便确认是否卡在商人窗口
- 支持 opt-in 的陌生道友邂逅婉拒、遭遇前自动护道、死亡复活、战斗用符、涅槃重生丹、奇遇固定选择
- 复制状态会显示陌生道友自动婉拒结果、触发来源、脱敏失败消息和下一步建议，方便确认是否卡在邂逅弹窗关闭入口
- 如果陌生道友自动婉拒重复执行但弹窗没有关闭，复制状态会在“诊断归因”里显示“陌生道友自动婉拒后仍未关闭”，方便手动处理或反馈弹窗结构
- 遭遇前自动护道可独立于自动迎战开启，会优先读取游戏当前自动护道设置；同一次遭遇只尝试一次，失败后暂停等待手动处理，复制状态会用中文显示护道结果、失败原因和处理建议
- 护道 1 倍模式如果同一遭遇已经尝试过自动护道，重复等待诊断会说明“本遭遇已尝试自动护道，避免重复扣费”，方便测试者手动处理而不是怀疑脚本漏点
- 死亡状态优先级高于残留遭遇/商人/奇遇面板；开启自动复活时会先复活再恢复挂机
- 战斗用符可配置 family 顺序/白名单，例如 `ghost,fire,shield`；留空则按原逻辑选择最高品质 family
- 同一次遭遇只会处理一次战斗用符；没符会跳过并记住，避免重复扫背包或反复消耗符箓
- 复制状态/摘要会只读背包做富裕资源预检，提示战斗符箓 family 数和史诗+涅槃重生丹是否可用
- 奇遇链默认暂停；可按全局第 N 项或 `adventureId -> choiceIndex` 策略表固定选择，未知奇遇状态会显示 ID、步骤、选项文本和可复制的策略候选行
- 复制状态会显示奇遇自动选择/关闭结果、奇遇 ID、选中的第几项、选项文本、触发来源、脱敏失败消息和下一步建议，方便确认是否卡在策略或按钮入口
- 如果奇遇自动选择重复执行但页面没有推进，复制状态会在“诊断归因”里显示奇遇 ID、自动选择的第几项和选项文本，方便修正策略或手动处理
- 检测到“灵界已更新新版本”提示时默认暂停并写入状态报告；可显式开启自动刷新页面
- 复制状态在游戏更新提示出现时会显示 helper 版本和“先刷新页面/重载扩展”的环境提示，方便排查测试者是否加载到最新版
- 混天典狱等不可安全跳过状态会显示“硬停:”和“硬停建议:”，明确脚本不会自动跳过、自动点击或消耗资源
- 自动挂机面板显示当前决策、上次动作和下次检查时间，方便测试者直接判断脚本是在等待、检查还是处理事件
- 复制状态会显示挂机阶段，例如冥想已过/剩余、满神识提前结束、探索倍率和卡住判定
- 复制状态会显示进入/结束冥想的执行结果、触发来源、触发原因（神识已满或冥想时长已到）、已冥想时长、计划分钟、脱敏失败消息和下一步建议，方便验证自定义 140 分钟循环是否真的收功
- 复制状态会显示自动探索启动结果、探索倍率、触发来源、脱敏失败消息和下一步建议，方便判断是否卡在倍率控件或自动探索入口
- 复制状态会显示自动复活结果、触发来源、脱敏失败消息和下一步建议，方便富裕 50 倍测试者确认战死后是否卡在复活阶段
- 复制状态会显示战斗用符结果、成功/失败 family 数、符箓面板是否关闭、脱敏失败消息和下一步建议，方便富裕 50 倍测试者确认是否卡在用符阶段
- 如果用符后符箓面板没有关闭，自动迎战会先停住并在状态里显示“符箓面板未关闭”，避免面板遮挡时误点或重复调用迎战；当前快照确认面板已关闭后会恢复迎战，不会被旧失败记录永久卡住
- 复制状态会显示自动迎战结果、触发来源、同遭遇去重状态、符箓面板阻断/恢复状态和失败建议，方便富裕 50 倍测试者确认用符后是否真的进入迎战且不会重复点击
- 复制状态会显示涅槃重生丹决策/执行结果、丹药名、品质、脱敏失败消息和下一步建议，方便确认富裕 50 倍是否卡在用丹阶段
- 自动挂机面板显示高风险动作预检，汇总迎战、护道、复活、用符、用丹、道友婉拒、奇遇自动选择和单轮资源上限的状态与警告
- 面板支持复制可读挂机状态报告，方便测试者先确认版本、风险、阻塞、资源用量和重复等待诊断归因
- 面板支持复制/导入挂机配置包，测试者可以共享固定挂机参数，导入时会自动关闭启动状态
- 面板支持粘贴脱敏摘要生成“摘要回放”，把测试者反馈还原成决策、阻塞、风险开关和奇遇策略表，并可一键把候选策略行导入本地策略表
- 支持复制挂机调试脱敏摘要，包含最近决策、等待诊断归因、日志、用丹/用符/迎战/护道尝试结果，方便测试者反馈停住原因和未知事件

#### 使用方法：
1. 安装脚本后，在游戏侧边栏会出现"自动开图"按钮
2. 点击按钮打开控制面板
3. 设置所需参数（开启数量、护道者配置等）
4. 点击"启动"开始自动化运行
5. 点击"停止"结束运行
6. 如果只是报当前情况，点击"复制状态"；如果需要开发者复现问题，点击"复制摘要"发送脱敏 JSON

#### 配置选项：
- 每次最多开启：设置单次最大开启数量
- 批量数量：设置批量处理的大小（1-10）
- 开启间隔：设置每次开启之间的延迟
- 自动雇护道：启用或禁用自动雇用护道者
- 雇佣费用限制：设置最高雇佣费
- 攻击力要求：设置最低攻击力要求
- 作战模式：选择协同作战或独立作战
- 妖兽设置：设置妖兽的生命值和攻击力限制
- 自动挂机循环：冥想分钟、最低神识、探索倍数、卡住判定、恢复窗口
- 挂机预设：稳妥 1 倍关闭资源消耗动作；护道 1 倍只开启遭遇前自动护道；富裕 50 倍开启迎战、复活、用符、涅槃重生丹
- 富裕模式开关：自动迎战、自动复活、自动用符、自动使用涅槃重生丹
- 资源上限：单次启动后的复活次数、用符遭遇数、用丹次数，`0` 表示不限
- 战斗符箓：最多 family 数、每类数量、可选 family 顺序/白名单
- 富裕资源预检：复制状态/摘要时只读背包，检查战斗符箓 family 和涅槃重生丹，不会使用物品
- 事件策略：陌生道友邂逅自动婉拒、奇遇链暂停/固定选择/按 ID 策略
- 页面更新：游戏提示新版本时默认等待；可开启自动刷新页面
- 实时状态：显示当前决策、上次动作和下次检查时间
- 风险预检：显示 7 个高风险动作的开关状态、护道参数、用符/用丹参数、资源上限和配置警告
- 状态报告：复制一段可读文本，包含版本、环境提示、当前决策、神识、阻塞、阶段/恢复剩余时间、预设匹配/偏离、回冥想原因、风险、冥想执行结果/建议、商人购买结果/建议、探索启动结果/建议、复活结果/建议、护道结果/建议、用符结果/建议、迎战结果/建议、用丹结果/建议、奇遇样本、资源用量和重复等待诊断归因；符箓面板未关闭时会在迎战行明确阻断原因，当前面板已关闭时会恢复后续迎战判断
- 配置包：复制当前挂机配置或导入他人的配置包；导入后不会自动启动挂机
- 摘要回放：粘贴调试摘要 JSON，生成问题回放视图和可复制的奇遇策略行；也可导入策略行，导入时只改本地配置且不会启动挂机
- 调试反馈：复制当前挂机脱敏摘要，包含神识、阻塞事件、奇遇 ID/选项、下一步决策、最近决策/日志、重复等待诊断归因、高风险开关状态、预设匹配状态、资源上限用量、富裕资源预检、冥想执行尝试、商人购买尝试、富裕模式用丹尝试原因、战斗用符尝试结果和符箓面板关闭状态、自动迎战触发来源/失败原因和护道尝试结果；URL query/hash 和长日志会自动压缩/脱敏

### 4. 灵界 LingVerse 修为简写显示 (lingverse-cultivation-compact.user.js)

这个脚本将修为数值简化为"几千万几亿"格式，解决手机端显示不全的问题。

#### 功能特点：
- 将大数字修为简化为中文单位（万/亿）
- 手机端自动启用简写显示
- 桌面端修为≥1000万时启用简写
- 鼠标悬停显示完整数值
- Hook游戏原生数据更新，零性能开销

#### 显示示例：
- 20,569,239 / 30,000,000 → 2056.9万 / 3000万
- 150,000,000 / 300,000,000 → 1.5亿 / 3亿
- 1,234,567,890 → 12.34亿

#### 安装方法：
1. 安装用户脚本管理器（如Tampermonkey、Greasemonkey或Violentmonkey）
2. 点击安装此脚本
3. 访问游戏网站即可生效

## 系统要求

- 浏览器支持用户脚本（如Chrome、Firefox、Edge等）
- 已安装用户脚本管理器（Tampermonkey推荐）

## 注意事项

1. 使用这些脚本时请遵守游戏的服务条款
2. 脚本仅为辅助工具，不保证完全无风险
3. 在更新脚本前建议备份个人配置
4. 如遇到问题，请检查脚本版本是否为最新
