# 灵界 (LingVerse) 游戏辅助脚本

这是一个针对灵界(LingVerse)网页游戏的用户脚本集合，旨在提升游戏体验和自动化一些重复性操作。

## 包含的脚本

### 1. 灵界 LingVerse 玩家ID显示 (lingverse-player-id.user.js)

这个脚本在主页状态栏、侧边栏和玩家资料面板显示当前玩家和其他玩家的数字ID，方便添加道友和拜访洞府。

#### 功能特点：
- 在顶部状态栏玩家名称后显示ID
- 在侧边栏角色信息区显示ID（境界下方）
- 在手机版状态栏显示ID
- 在查看其他玩家资料时，在名称旁显示其ID
- 点击ID可复制到剪贴板
- 复制成功显示提示

#### 安装方法：
1. 安装用户脚本管理器（如Tampermonkey、Greasemonkey或Violentmonkey）
2. 点击安装此脚本
3. 访问游戏网站即可生效

---

### 2. 灵界 LingVerse 神识精确数值显示 (lingverse-spirit-exact.user.js)

这个脚本将主页状态栏的神识百分比改回准确数值，并在使用神识时实时更新显示。

#### 功能特点：
- 将神识显示从百分比转换为精确数值（例如：120/200 而不是 60%）
- 显示神识恢复倒计时
- 实时更新神识数值
- 支持主界面和状态栏两处神识显示的更新

#### 安装方法：
1. 安装用户脚本管理器（如Tampermonkey、Greasemonkey或Violentmonkey）
2. 点击安装此脚本
3. 访问游戏网站即可生效

---

### 3. 灵界 LingVerse 自动开藏宝图 (lingverse-explore-helper.user.js)

这个脚本可以自动开启背包中的藏宝图，并处理遇到的战斗。

#### 功能特点：
- 自动扫描并开启背包中的藏宝图
- 支持批量处理，可设置每次开启的数量
- 遇到战斗时可自动雇用护道者
- 提供气运状态显示和统计信息
- 可配置护道者雇佣条件（最高费用、最低攻击力等）
- 支持多种作战模式和优先级设置

#### 使用方法：
1. 安装脚本后，在游戏侧边栏会出现"自动开图"按钮
2. 点击按钮打开控制面板
3. 设置所需参数（开启数量、护道者配置等）
4. 点击"启动"开始自动化运行
5. 点击"停止"结束运行

#### 配置选项：
- 每次最多开启：设置单次最大开启数量
- 批量数量：设置批量处理的大小（1-10）
- 开启间隔：设置每次开启之间的延迟
- 自动雇护道：启用或禁用自动雇用护道者
- 雇佣费用限制：设置最高雇佣费
- 攻击力要求：设置最低攻击力要求
- 作战模式：选择协同作战或独立作战
- 妖兽设置：设置妖兽的生命值和攻击力限制

## 系统要求

- 浏览器支持用户脚本（如Chrome、Firefox、Edge等）
- 已安装用户脚本管理器（Tampermonkey推荐）

## 注意事项

1. 使用这些脚本时请遵守游戏的服务条款
2. 脚本仅为辅助工具，不保证完全无风险
3. 在更新脚本前建议备份个人配置
4. 如遇到问题，请检查脚本版本是否为最新
